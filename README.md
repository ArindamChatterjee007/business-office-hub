# Business Office

Public portfolio hub for three business units, with one registry for future additions.

- Live site: https://arindamchatterjee007.github.io/business-office-hub/
- Pages contain public unit descriptions and approved project/source links only.
- GitHub controls access to the linked private repositories and Projects. A public page is not a private login session.
- The custom protected dashboard and its OAuth setup are separate and are not enabled by this release.
- No client correspondence, personal documents, private finance or credentials are included here.

Built and tested on GitHub-hosted runners. The reviewed public registry produces the navigation and unit dashboards; additional units do not require new view code. Publish only validated public build output.
